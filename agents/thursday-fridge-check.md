# Thursday fridge check

Runs Thursday at 7:20 p.m. in a session that waits for a reply. Writes one file.

---

Weekly Thursday evening fridge check for [Household]'s food plan. [Person] asked to be reminded every Thursday night so nothing goes to waste.

1. Right away, send a push notification that says: "Fridge check for tomorrow's food plan: reply here with anything open or left over that needs using up (cheese, cream, herbs, half bags of produce, leftovers). I'll save it so Friday's plan uses it first."
2. Wait for the reply in this session. Never use em dashes or hyphens as dashes.
3. When the reply arrives, write the list to `fridge-leftovers.txt` in the Weekly Food Plan folder on the family computer using the device file tools. Replace the file's contents with a header line "Fridge leftovers to use up, saved <today's date>" followed by one item per line with any amounts or notes given. If the reply says there is nothing, write the header and "Nothing to use up this week."
4. Confirm back in one short message what was saved. Do not edit any other file, and do not touch the store.
